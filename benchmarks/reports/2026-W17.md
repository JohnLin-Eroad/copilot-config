### Security Review (69.0/100)
**Prompt:** DriverAuthController security review with 3 planted vulnerabilities.

100% recall — all 3 planted vulnerabilities found. But precision heavily penalized.

**Found (planted):**
1. ✅ Privilege escalation via /update-role (SF-001, CRITICAL) — correct
2. ✅ Weak SHA-256 password hashing (SF-002, CRITICAL vs ground truth HIGH)
3. ✅ JWT validation not explicit (SF-007/SF-010, HIGH) — correct

**Additional findings (genuine but not planted):**
- Non-constant-time hash comparison (bonus acknowledged in ground truth)
- Username enumeration
- No rate limiting
- Stack trace leaks
- No input validation on role
- No audit logging

**Scoring tension:** The precision formula (true_positives / total_flagged) punishes thoroughness. The agent found 10 real security issues but only 3 were "planted." In a real security review, finding 7 additional genuine vulnerabilities is excellent work. This rubric design may need revisiting.

## Recommended Actions

1. **Security review rubric** (Priority: HIGH) — Precision formula punishes thoroughness. Consider: count only FALSE positives as negatives, or adjust formula to `(true_positives) / (true_positives + false_positives)` where genuine security issues count as true positives regardless of whether they were "planted."

2. **Pipeline model reporting** (Priority: MEDIUM) — Orchestrator should log which model each specialist agent used. Currently not reported, causing 50/100 on model selection dimension.

3. **Context retrieval gap handling** (Priority: MEDIUM) — Train brain-data-retrieval to note vault-level uncertainty markers (e.g., "(inferred)") when relaying information.

4. **Benchmark methodology: Javadoc truncation** (Priority: HIGH) — Grading prompt must include FULL executor output, not truncated summaries. The code-generation Javadoc dimension had to be manually adjusted. Automate full-output passing to grader.

5. **VehicleController existence** (Priority: LOW) — Consider adding a reference VehicleController to ~/sovereign for pipeline-compliance benchmarks, or rotate prompts to use existing controllers.
