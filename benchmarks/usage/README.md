# Usage Reports

Weekly snapshots of token consumption, model distribution, agent/skill/tool usage.

## Directory Structure

```
usage/
├── README.md              ← This file
├── YYYY-WXX.json          ← Weekly usage snapshot (auto-generated by benchmark-runner)
└── YYYY-WXX.md            ← Human-readable usage report (auto-generated)
```

## How it works

Usage data is extracted from session `events.jsonl` files in `~/.copilot/session-state/`.

**Token sources:**
- **Sub-agent tokens** (exact): from `subagent.completed.totalTokens` events
- **Main session tokens** (heuristic): estimated from `session.compaction_complete.preCompactionTokens` — the context window size captured before each compaction. This is a conservative undercount; short sessions with no compaction show 0 for this field.

**Agent calls**: from `subagent.started` / `subagent.completed` events  
**Skill calls**: from `tool.execution_start` where `toolName == "skill"`  
**Tool calls**: from all `tool.execution_start` events  
**Model distribution**: from `subagent.completed.model`

## Generating Reports

### On-demand (terminal)
```bash
copilot-usage                    # all-time + latest week
copilot-usage --week 2026-W16    # specific week
copilot-usage --json             # JSON output
```

### Automatic
- Updates `~/.copilot/logs/usage-stats.json` at the end of every Copilot session (via the `copilot()` zsh wrapper)
- Weekly snapshot appended to this directory by the `benchmark-runner` agent on Mondays

## Interpreting the Data

| Field | Notes |
|---|---|
| `subagent_tokens` | Exact token count for all sub-agents launched via the `task` tool |
| `main_session_tokens_heuristic` | Estimated from compaction events — undercount for sessions without compaction |
| `total_tokens_estimated` | Sum of both — best available total, still conservative |
| `by_model` | Token + call breakdown per model for sub-agents only |
| `agents` | Call count, token usage, avg duration per named agent |
| `skills` | How many times each skill was invoked |
| `tools` | Raw tool call frequency across all sessions |
