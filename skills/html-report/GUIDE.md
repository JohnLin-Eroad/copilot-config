# HTML Report — Guide (Tier 2)

Step-by-step process for generating an HTML report. Read this when you are ready to build.

---

## Step 1 — Determine the session files path

```bash
SESSION_ID=$(ls -t ~/.copilot/session-state/ | head -1)
FILES_DIR="$HOME/.copilot/session-state/$SESSION_ID/files"
mkdir -p "$FILES_DIR"
```

## Step 2 — Choose a filename

Use kebab-case, descriptive names. Include the date if periodic.

```
<topic>-report.html          # e.g. ai-benchmarks-report.html
<topic>-<date>.html           # e.g. weekly-learnings-2025-W29.html
<topic>-analysis.html         # e.g. auth-flow-analysis.html
```

  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>REPORT_TITLE</title>
  <style>
    /* Paste the FULL Design System CSS from DETAIL.md here */
  </style>
</head>

  <aside class="sidebar">
    <div class="sidebar-header">
      <h2>SIDEBAR_TITLE</h2>

## Step 4 — Write the file and open it

```bash
cat > "$FILES_DIR/my-report.html" << 'REPORT_EOF'
<!DOCTYPE html>
...full HTML here...
REPORT_EOF

open "$FILES_DIR/my-report.html"
```

## Step 5 — Confirm to the user

```
📊 Report saved to: ~/.copilot/session-state/<session-id>/files/<name>.html
🌐 Opened in browser.
```

---

## Quality Tips

1. **Lead with a stat row** — 3–5 KPIs at the top for the headline
2. **Badge all status columns** — never plain text
3. **One callout per section max** — overuse dilutes impact
4. **Sidebar nav must match sections** — every `<section id="...">` needs a nav link
5. **Card grids for comparisons** — side-by-side beats long prose
6. **Score bars over plain numbers** — visual data is faster to scan
7. **Date the report** — always in the sidebar footer
